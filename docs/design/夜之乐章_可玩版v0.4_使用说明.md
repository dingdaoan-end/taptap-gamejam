# 夜之乐章 · 可玩版 v0.4

## 进入游戏

- Windows：打开 `Builds/MusicGarden-v0.4/Nocturne.exe`。分享时需要整个文件夹，不能只发 exe。
- 团结工程：打开 `Assets/Scenes/MusicGarden.unity`，点击 Play。
- 编辑器菜单：`Tools → Music Garden → Open Playable Scene`。

## 操作

1. 开场完整展示四区约3秒，再平滑移到左上区。整备和战斗时镜头严格框住25×13格，即整图四分之一；宽屏或较方的窗口会留出空白以适配地图比例，不露出邻区。初始已有三座示范钢琴，生命和金币在顶部。
2. 左键点击琴塔看有效射程。紫色可攻击，红色被障碍挡住。整备或间奏可回收，并在任意空闲草地重新建造；石台只推荐位置。道路、障碍、基地与已占用格不可建造，仍受金币与六塔上限约束。
3. 点击开始或按空格。普通怪击杀产生 Do、Mi、Sol；和弦怪有三点生命，和弦塔擅长重拍清理它们。
4. 选普通钢琴按 R 接管；A = Do，S = Mi，D = Sol。预约下一尚未锁定拍，重按会覆盖；不按即休止。只有同音目标被实际击杀才发声。
5. 按 R 切回自动。四个按钮改变伴奏节拍；“全部／只弹／跳过”设置音高筛选。
6. 多座琴塔在同一拍击杀并奏出 Do、Mi、Sol，触发合奏休止。存活敌人停一步，新来的敌人不受前一次休止影响。
7. 每16拍有间奏，可全额回收与补塔。区域完成后点击下一乐章，生命恢复2点；四区预算各自重置。
8. 空格暂停／继续。失守可重试本区。完成后回放整局真实击杀乐谱。

第一关建议：试着接管中间的钢琴，隔一拍留白，在另外两座钢琴的反拍上应答。提前连续击杀与等待合奏都会形成不同的记录。

## 在团结内修改

场景中的1300个地块、48个建造位、预设钢琴、Canvas均已保存。

- `Editable Region / 地块`：`GardenTile.kind` 控制草地、道路、阻隔、基地；显示与战斗都会读取。改地形后应同步检查配置中的有序路线，路线不能跨过非道路格。
- `建造位 / GardenPad`：石台是推荐位置与示范编排的候选位置。修改所属区域与格子，或禁用这个对象，不会禁止普通草地建造。
- `预设琴塔 / GardenTowerSetup`：拖到空闲草地格中心，修改节拍、筛选音、类型。启动时从对象位置和设置读取，花费该区预算；修改 SpriteRenderer 的贴图、颜色、缩放也会用于实际游戏。禁用 GardenTowerSetup 或整个对象可以取消预设。
- `Canvas`：直接修改文字、字号、位置、颜色和按钮布局。
- `Assets/MusicGarden/Data/GardenConfig.asset`：节奏速度、四区预算、波次、素材、和弦射程模板。可切换附件7的菱形射程与PRD建议方形射程。
- `Assets/MusicGarden/Prefabs`：普通琴、和弦琴、普通／快速／和弦怪的独立预制体，已经接入运行时生成。可修改 SpriteRenderer 或在配置中换成自己的预制体。预设琴塔是普通琴预制体的场景实例，可单独覆盖外观。

`Create Playable Scene` 是开发用重建入口，会根据精确地图重新生成默认场景；完成手工关卡编辑后，请使用 Open / Build 菜单。

## 当前内容边界

这是验证玩法的小版本：钢琴一个音色、两类塔、三类敌人、四区依次激活。道路和障碍沿用逐格参考数据，每区先启用一条已配置的道路入口；其他已画道路仍保留。自动伴奏可通关，领奏选择和留白会改变真实音乐与共鸣。

本版使用PRD建议的射程可重叠和软克制；和弦默认方形5×5，可在配置里换菱形。尚未加入小提琴音色、音量分轨、四拍完整预测和最终平衡。本版波次较短，供团队迅速试玩核心循环。

已知细节：选择空草地时先显示普通塔射程，建好和弦塔后显示和弦射程；金币提示可能比声音提前约80毫秒更新。
