# 2×2 建造机制

场景：`Assets/Scenes/Map.unity`、`Assets/Scenes/MusicTest.unity`。

## 玩家操作

1. Play 后把鼠标移到地面，显示吸附网格的 2×2 预览：绿色可以建造，红色不能建造；建造状态不显示文字提示或底部提示条。
2. 点击绿色区域，使用原来的建造菜单选择塔。
3. 点击已有塔的底部占地区域，选择拆除。右键或 Esc 取消选择。

只有五项全部满足才允许建造：四格均为 Ground level 1/2/3/4；四格同层且完整；整块不接触已有塔的实际攻击范围；四格完整边界都在当前相机视口内；没有障碍或已有塔占位。

每次点建造按钮都重新校验。打开菜单之后移动/缩放镜头、新增障碍、或者另一座塔先建成，都会立即影响是否可以建造。新塔的射程与旧塔射程之间可以相交；这里限制的是新塔的 2×2 占地区域不能进入已有塔射程。

## 编辑器配置

- `BuildManager` 上的 `BuildPlacementValidator` 引用实际 Tilemap。认可的名字为 Ground level1～Ground level4，允许空格/下划线。旧 MusicTest 的 Ground 已改名为 Ground level1，地形内容不变。
- Ground 下的障碍对象会按其 Collider2D 或 SpriteRenderer 范围占位；子障碍 Tilemap 也会占位。Ground 自身的地形碰撞体不应把整个地面当成障碍。
- Map 已合并 GitHub 的 `cac9a9b` 石块更新。独立的 `Obstacle` Tilemap 已绑定为占位图层，不需要额外添加碰撞体；在该图层绘制或擦除石块，会直接影响对应 2×2 是否可以建造。
- 道路 Paths、基地 Base 的 Tilemap 视为占位。Water 和 Ground bottom 不属于合法建造层；不要把铺在地面下的整张 Water 图层配置为障碍图层。
- 不在 Ground 层级内的障碍，可以添加 `BuildObstacle`，通过 Inspector 设置占位尺寸，或使用其精灵包围盒；选中后显示占位线框。
- 现有塔的范围取 `TowerEnemyDetector` 所在对象的 Collider2D，和实际索敌范围保持一致。
- `Canvas/Build placement status` 是可编辑的场景 UI，负责显示建造结果与失败原因。
- 新场景配置可用菜单 `Tools → Building → Configure Current Scene`，此操作会添加建造校验和提示，并把该场景中名为 Ground 的旧地块改名为 Ground level1。

自动检查入口：`BuildPlacementChecks.RunBatch`。覆盖五项条件及跨层、缺角、负坐标、YXZ 网格、局部射程相交、视口边缘、选择后环境变化、拆除与重建；并检查两张实际地图均存在可用位置。
