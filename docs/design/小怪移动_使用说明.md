# 小怪移动

## 直接体验

打开 `Assets/Scenes/Map.unity` 并 Play。新版 Minion 会从左上入口按音乐节拍陆续出生，沿道路中心持续前进，转弯时改变方向，抵达靠近基地的终点后退场。

- 默认移动速度：每拍 1 个世界单位；出生间隔：4 拍。改变背景音乐 BPM，单位时间内的移动速度也会随之改变。
- 暂停 MusicClock，小怪的位置和步行动效都会冻结；恢复后从原进度继续。
- 每只小怪保留出生时的入口与路线。修改路点、移动入口或调整后续路线，不会让场上的小怪突然改道。
- 小怪仍有生命，可以被现有节拍攻击击杀；被击杀的小怪不会再计入抵达数量。
- 当前美术是单张静态图，使用水平翻转、轻微上下浮动和摇摆表现步行，保留美术原本缩放。没有虚构逐帧动画。

## 在编辑器中调整

Hierarchy 新增 `Enemy Movement`，下分 NorthWest、NorthEast、SouthWest、SouthEast 四组。当前地图有 7 条独立道路，因此配置了 7 个入口。默认只有第一个 NorthWest 入口的生成器启用，其他入口可选中后启用其生成器组件，便于后续接入分区或波次控制。

每个入口包含：

| 对象／设置 | 用途 |
| --- | --- |
| SpawnPoint | 出生位置，应放在对应道路格内 |
| Goal | 该条道路靠近基地的终点，应放在道路格内 |
| Route / Waypoint | 在 Scene 中显示完整路线，打开 Gizmos 可查看 |
| Enemy Audio Test Spawner / Units Per Beat | 移动速度，可在运行中调整，设为 0 停止移动 |
| Spawn Interval Beats | 出生间隔拍数 |
| Arrived Count | 本次音乐播放期间抵达终点的数量 |
| Enemy Test Route / Rebuild From Road On Start | 开始时根据当前 Paths 与 Obstacle 重建路线 |

编辑道路后，使用 `Tools → Enemies → Configure Map Movement` 更新路线预览。Play 时也会根据当前道路和石块重新检查连通性；入口不在道路上或道路被石块切断时，该入口停止生成并在 Console 说明原因，不会穿越草地或石块直奔基地。

运行中移动入口、终点或修改道路，会在下一批出怪前重新寻路。若新的路线无效，跳过这批出怪，场上已有小怪仍沿出生时的路线继续移动；修好后可在后续出怪拍恢复生成。

普通路点路线仍受支持：取消 `Rebuild From Road On Start`，可直接拖动 Route 下的 Waypoint。已有 `MusicTest` 保留原手工路线，并自动使用新版 Minion Prefab。

`Assets/Prefabs/Enemy.prefab` 上的 `Enemy Walk Visual` 可调整浮动高度、步幅和摇摆角度。攻击范围仍按敌人的实际 Collider2D 检测。

本次只实现移动、出怪、转向、死亡衔接和抵达统计；抵达暂不扣基地生命，也没有自动切换分区或波次。

## 验证

- `EnemyMovementChecks.RunBatch`：路径采样、拐弯、不可变路线、速度、100/116 BPM、暂停恢复、掉帧、抵达、死亡、石块绕行及实际 Map 路线。
- `EnemyMovementPlayChecks.RunBatch`：实际进入 Map 的 Play 模式，验证新版小怪移动、转向、步行动效、暂停恢复与一次抵达。加速参数仅用于临时测试，不保存到地图。
