# 建造与拆除菜单自适应

选中防御塔时，拆除按钮优先使用原来的位置。靠近画面边缘时，整个按钮和文字会向内移动，保持在当前世界摄像机的可见区域内，不进入黑边。建造菜单共用同样的边界规则。

- 使用实际显示的按钮和文字边界计算，忽略未显示的选项。
- 适配 Canvas 缩放与相机视口变化；空间不足时等比缩小菜单。
- BuildSelection 的 **Menu Edge Padding** 控制距离视口边缘的像素间距，默认 8。
- **Menu Offset** 仍控制正常位置的偏移；拆除按钮的原有点击绑定保持有效。
- 菜单位置在固定视野相机更新之后计算，窗口比例变化时会重新约束。

验证入口：BuildMenuViewportChecks.RunBatch。RED 在画面左下角复现拆除按钮越界；GREEN 在实际 Map 场景完成 1203 项边界与功能断言，覆盖四种视口、三种 Canvas 缩放、九个锚点位置、极窄区域缩放，以及实际建造菜单和拆除按钮点击。日志：Logs/build-menu-red.log、Logs/build-menu-final.log。测试对象与参数变更不保存到场景。
