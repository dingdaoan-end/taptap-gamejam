- 附件 6 的紫色半透明区域属于射程演示，不能当作新增路面或改变地块。占格取自清晰的单图 1–4，拼装方位取自总览 6。
- 蓝色是**阻隔**，用密实树丛／墙体表达；不会解释为水池。
- 图片编号表示附件编号与空间位置，不自动指定游戏激活顺序。贴边黄色格也不自动全部变成出生点。

数据文件：[map-layout.json](map-layout.json)。坐标从左上开始，x 向右、y 向下、下标从 0 起。G＝草地，R＝道路，X＝阻隔，B＝基地。包含单区数组和完整 50×26 数组，后续可转换为团结 Tilemap 数据。

## 美术如何继续

1. 沿原图道路占格替换直段、转角、连接边，保持一格宽及原有连接。
2. 以相同格坐标替换障碍模块；树冠和石墙的装饰边缘不得遮掉路。
3. 草地上装饰密度可以调整，塔位需另行配置，不能为放置大琴塔移动道路。
4. 基地允许更换音乐核心外形，所有原来接入基地的道路格保留。
5. 先在这份固定路网中安排波次、行进方向与塔位；不会为了缩短等待直接删路。
